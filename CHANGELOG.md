# Changelog

## 0.1.0 — first public preview (unreleased)

- Automatic on-screen RS detection with native Windows OCR.
- Mining resource and rock-count estimates, plus salvage panel detection.
- Visual text proposals, local tracking and contextual OCR fallback for head movement.
- Stable readings with distance rejection and a short tolerance for OCR misses.
- A compact top-edge overlay with LOW / MEDIUM / HIGH mineral hints.
- A minimal dark control window, native tray controls and Ctrl + Alt + F8.
- Original vector icon with separate Windows sizes from 16 to 256 px.
- Portable Rust executable, MIT license, source documentation and Windows CI.

Mining results have been reported working in game during development. Salvage is covered by synthetic fixtures; broader in-game validation remains open. Difficulty is indicative and signatures can change with game patches.
